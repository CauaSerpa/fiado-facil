Configurações

Exportar dados

Baixe uma cópia completa do seu banco de dados incluindo clientes, fiados, pagamentos e configurações. Esse arquivo pode ser usado para backup ou migração.

Importar dados

Restaure um backup anterior do sistema. Isso pode substituir os dados atuais dependendo do arquivo importado.

Área de risco

Esta ação irá apagar permanentemente todos os dados do sistema, incluindo clientes, fiados e pagamentos. Não é possível desfazer esta operação.
